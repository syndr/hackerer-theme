# Cursor Themes

## Broodwar

StarCraft: Brood War animated cursor theme for Linux.

**Author:** CORVIAN
**Source:** https://store.kde.org/p/1680392
**Description:** Original Brood War cursor extended with shadows for Linux

All StarCraft/Brood War trademarks are property of Blizzard Entertainment.

### Formats

- `cursors/`: XCursor, as published by the author.
- `manifest.hl` + `hyprcursors/`: a hyprcursor build of the same images, so
  Hyprland scales the cursor per monitor. Converted with
  [`xcursor-to-hyprcursor.py`](https://github.com/syndr/hyprland-wm-config/blob/main/scripts/xcursor-to-hyprcursor.py);
  no artwork was changed.
